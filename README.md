# E-Commerce-Customer-Behavior-Analysis

## Overview

This project analyzes customer purchasing behavior using a real-world e-commerce dataset.

The goal is to identify:

- Monthly sales trends
- Top performing products
- Country-wise revenue
- Customer value segments

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- SQL (SQLite)

## Key Features

### Data Cleaning
Removed missing customer IDs and invalid transactions.

### Revenue Analysis
Calculated total revenue generated by each transaction.

### Product Analysis
Identified top-performing products based on revenue.

### Customer Segmentation
Categorized customers into:
- High Value
- Medium Value
- Low Value

### Database Integration
Stored cleaned transaction data in SQLite database.

## Output

The project generates:

- monthly_sales.png
- top_products.png
- country_sales.png
- customer_segments.csv
